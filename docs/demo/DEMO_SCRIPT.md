# Demo script: word for word

About 365 spoken words: 2:55 at a steady 125 words a minute. If you run long in rehearsal, drop the Muse Voice sentence first.

**Marks:** **bold** = stress the word · `/` = short pause · `//` = full breath · *(slower)* · *(lift)* = sound pleased, not loud · ▶ = change screen.

---

**0:00–0:20 · The problem** ▶ *Home page, still*

> If you use a wheelchair, / or you can't see well, / or you can't hear an alarm, / the question is the same: / **will this place work for me?** //
> Usually all you get is one "accessible" sticker. / And one label can't answer **five different** needs.

**0:20–0:42 · What PathAble is** ▶ *Scroll to the needs and how-it-works sections*

> I'm Vishal, and I built **PathAble AI** during this hackathon. / It brings accessibility information for one campus, / **IIT (ISM) Dhanbad**, / into one place. / It covers moving around, / seeing, / hearing, / finding your way / and comfort, / not only wheelchair access.

**0:42–1:15 · Personal discovery** ▶ *My needs → choose Mobility and Wayfinding → home search "library" → Central Library*

> First, my needs. / They stay in my browser. // *(slower)* Now I search for the library. / Search only ever returns places **inside the campus boundary.** //
> The profile leads with **my** details: / step-free way in, / ramp, / lift, / toilet. / And right now, / every one of them says **unknown.** // *(slower)* That's the honest answer: / nobody has recorded them yet. / An app that showed a green tick here would be guessing. / Every detail that *is* added carries its source and its date, / and there's no score, on purpose.

**1:15–2:00 · Meta AI, with a person in charge** ▶ *Report a barrier here → photo → analysis → outlines → review*

> Now I report a barrier here, / with a photo. //
> **Muse Spark 1.3** reads the scene / and suggests possible barriers, / each with what it can see, / why it may matter, / and what the photo **can't** show. //
> Then **SAM 3.1** outlines the evidence, / so I can see exactly *which* object the suggestion is about. / *(lift)* That's the scooter, across the ramp. //
> But nothing becomes a report until **I** decide. / I confirm this one, / and reject this one, / because it's a shadow. / If I'm on the move, / **Muse Voice Transcribe** turns a spoken note into text.

**2:00–2:35 · Trust** ▶ *Privacy box → Share → owner Approvals → place page again*

> The report is linked to **this** place, / and the photo's location data is removed in the browser. // ▶
> It stays private until it's approved. / On the owner side, / I check it for faces and personal details, / then approve it. // ▶
> On the library page, / the barrier now appears / as **"confirmed by reporter"**, / with its date. / *(slower)* Suggested by AI, confirmed by a person, independently verified. / Those are **three different things**, / and PathAble never blurs them.

**2:35–3:00 · Close** ▶ *Place page, then home*

> So this isn't an image analyser. / It's place intelligence: / needs-first, / evidence-backed, / and checked by people. // *(slower)* It starts with one campus, / and the same structure works for the next one. //
> **One world. / Different needs. / More accessible journeys.**
