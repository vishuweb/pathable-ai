# Demo QA checklist

## Two hours before

- [ ] Meta promotional balance confirmed in your Meta dashboard, and usage cannot be charged to you. Otherwise use backup B or C.
- [ ] `https://pathable-ai.vercel.app/api/health` shows the key as configured and Blob as storage.
- [ ] `AI_PAUSED` is not set on Vercel (only if you are going live with AI).
- [ ] Owner key at hand, and you can sign in at `/owner` in window B.
- [ ] Demo photo chosen: your own photo of a campus path or entrance, with **no faces and no number plates**. Or use the built-in sample *Fallen scooter on a sidewalk*.
- [ ] One rehearsal of the full shot list (about 2 live AI calls). Delete the rehearsal report afterwards.
- [ ] Script read aloud three times, then timed: 2:45–2:58.

## Just before recording

- [ ] Do Not Disturb on, other apps closed, charger in.
- [ ] Window A: private, 110% zoom, on `/`, no needs chosen.
- [ ] Window B: signed in, on `/owner/moderation`, with nothing old waiting in the queue.
- [ ] Mic test recorded and played back.
- [ ] Nothing private visible: no key, no `.env`, no terminal, no email, no other tabs.

## Watch the take before keeping it

- [ ] Every beat happened: needs → search → profile → report → outlines → confirm → share → approve → place updated.
- [ ] The change from **Suggested by AI** to **Confirmed by reporter** is visible.
- [ ] Nothing claims model accuracy, campus surveys, users or verification that hasn't happened.
- [ ] If the illustrative demo is shown, the notice *Illustrative demo — not verified campus data* is on screen and you said so out loud.
- [ ] Under 3:00. Audio is clear, with no clipping.

## Submitting

- [ ] Captions checked by hand.
- [ ] The video link works in a private window.
- [ ] The README has the video link. The repository is public, and `main` is the version you recorded.
- [ ] The form text points to `HACKATHON_CONTRIBUTIONS.md` for what was built during the event.
- [ ] Indie-track rules re-read on the event dashboard: video length, hosting, licence and repository visibility.
- [ ] The demo report is deleted from the live site if you don't want it public.
- [ ] Submitted before **Nov 4, 2026, 9:00 PM ET (Nov 5, 7:30 AM IST)**, ideally at least an hour early.
